# D-Day 3 · 3.5.7

시계·음력·달력과 여러 D-Day를 투명한 유리 패널에 표시하는 Windows용 무료 위젯입니다.

- 공식 안내: https://mathtime.kr/dday.html
- 소스·배포: https://github.com/lottoria-dev/MyDDayWidget-Source
- 문의: mathtime.ai@gmail.com
- 실행 환경: Windows 10/11 x64, .NET Framework 4.8 이상

## 3.5.7 변경 사항

- 설정에서 날짜를 선택할 때 달력 상단의 연도와 월이 잘리지 않도록 수정했습니다.
- 부팅 중 파일 접근이 지연되면 설정 읽기를 재시도하고, 원본이 없어도 정상 백업을 먼저 확인합니다.
- 설정을 온전히 읽지 못하면 저장 보호 상태로 실행합니다. 이동·크기 조절·종료·메뉴 조작으로 기존 파일을 덮어쓰지 않습니다.
- 위치·크기만 바꿀 때는 최근 3세대 백업을 교체하지 않습니다. 날짜별 최초 정상 사본도 최대 14개 보관합니다.
- **백업 선택·복원…**에서 날짜와 D-Day 개수를 보고 복원할 사본을 선택합니다.
- 설정 파일에 무결성 확인값과 D-Day 개수를 기록하고, 파일 교체 실패 시 원본을 일반 복사로 덮어쓰던 경로를 제거했습니다.

전체 정식 버전 이력은 [CHANGELOG.md](CHANGELOG.md), 이번 릴리스 안내는 [RELEASE_NOTES.md](RELEASE_NOTES.md)에 있습니다.

## 다운로드와 실행

GitHub Releases에서 `DDay3-v3.5.7-win-x64.zip`을 내려받아 폴더에 압축을 푼 뒤 `DDay3.exe`를 실행합니다. 실행 파일과 `DDay3.exe.config`, 함께 제공되는 세 DLL 및 라이선스 파일을 같은 폴더에 두세요.

공식 배포 파일의 SHA-256은 Release의 `DDay3_SHA256.txt`와 비교할 수 있습니다.

```cmd
certutil -hashfile DDay3-v3.5.7-win-x64.zip SHA256
```

## 기본 사용법

| 동작 | 사용 방법 |
| --- | --- |
| 환경 설정 | 위젯의 빈 공간을 더블 클릭하거나 트레이 메뉴에서 설정 선택 |
| 이동·크기 조절 | 빈 공간을 드래그해 이동, 오른쪽 아래 모서리를 드래그해 확대·축소 |
| D-Day 등록 | 설정의 D-Day 탭에서 제목과 목표 날짜 입력 후 저장 |
| 표시 개수 | D-Day 탭 하단에서 1~10개의 정수 입력 또는 +/− 버튼 사용 |
| 다른 일정 보기 | 표시 개수를 넘는 일정은 위젯 위에서 휠 또는 방향키로 순환 |
| 목록 정렬 | 설정에서 날짜순·오늘과 가까운 날순·제목순 정렬 또는 날짜 선택기 오른쪽 ↑↓ 사용 |
| 달력 이동 | 이전·다음 달 버튼 사용, 연·월 제목을 눌러 원하는 달로 직접 이동 |
| 화면 밖 위젯 복구 | 트레이 메뉴의 **주 모니터로 가져오기** 선택 |
| 종료 | 트레이 메뉴에서 종료 선택 |

목표 날짜까지는 D−, 당일은 D-Day, 지난 날짜는 D+로 표시합니다. 저장된 보조 모니터 위치는 부팅·절전 복귀 때 자동으로 바꾸지 않습니다.

## 글꼴과 화면 설정

- 글꼴·색상 탭에서 시간·날짜·D-Day 제목·남은 일수·목표 날짜·달력을 한 표로 비교하며 글꼴·굵기·색상·정수 pt를 각각 지정합니다. 내부 표시 크기는 창 배율에 맞춰 연속값으로 계산합니다.
- 시계 기본 서체는 Consolas입니다. 설치된 고정폭 서체를 우선 추천하며 영문·한글 추천 세트를 제공합니다. 추천 서체 적용은 항목별 크기·색상을 유지합니다.
- 밝은 글자·어두운 글자·사용자 지정 색상 중 선택합니다. 빠른 테마와 대표 색상의 자동 조화는 글자색만 바꾸며 유리판 색상·농도·글꼴·크기는 유지합니다.
- 전체 배경·시계·D-Day의 유리판 농도를 각각 5~100%로 조절합니다. 글자를 선명하게 두고 싶으면 글자 선명도는 100%로 유지한 채 패널 농도만 낮추세요.
- 각 패널의 양각·음각 깊이와 5가지 조합 프리셋을 제공합니다. 전체 배경은 −100~+200, 시계·D-Day는 −100~+100이며 깊이 0은 평면입니다.
- 공통 광원 다이얼과 직접 숫자 입력으로 빛의 방향을 조절합니다. 평상시 얇은 흰색 경계선과 마우스 오버 혜성은 각각 켜거나 끌 수 있습니다.
- 달력의 일요일·월요일 시작, 주말 색상, 음력과 윤달 표시를 선택합니다. 영문에서는 Solar / Lunar로 표시하며 설정한 날짜 형식을 함께 적용합니다.
- 12/24시간제, 초 표시, 스톱워치, 바탕화면 격자 맞춤, 항상 위에 표시, Windows 시작 시 실행을 지원합니다.

### 굴절광

**표시·동작 → 유리판 농도·깊이 → 파스텔 굴절광**에서 꺼짐·은은하게·선명하게·프리즘 중 선택합니다. 단색 모드는 무채색·하늘·민트·라벤더·로즈·피치와 직접 지정 색상을 제공합니다.

프리즘은 좁은 유리 단면에 분홍·보라·파랑·청록·녹색·노랑을 연결하고 작은 백색 반사점을 더합니다. 양각은 바깥 모서리, 음각은 조금 안쪽에 빛이 맺히며 깊이와 광원 방향에 연동됩니다. 패널 중앙과 글자에는 효과를 적용하지 않습니다. 실제 바탕화면을 촬영하거나 물리적 굴절을 계산하지 않습니다.

프리즘을 선택해도 기존 단색은 보관하며 다른 모드로 돌아가면 다시 사용합니다. 기본 모드는 은은한 하늘색이고 기존 설정은 유지합니다. 효과는 미리보기 후 저장하며 취소하면 원래 설정으로 돌아갑니다.

### 임박 D-Day 색상

**표시·동작 → 3일 이내 D-Day 색상 자동 적용**을 켜면 오늘부터 3일 뒤까지 캡슐 배경과 제목색을 구분합니다. 앰버·로즈·민트·블루 세트 또는 배경·제목의 사용자 지정 색상을 사용합니다. 지난 일정은 원래 색상을 유지하며 배경색은 유리판과 옅게 혼합합니다.

## 캘린더 연동

**설정 → 캘린더 연동 → 캘린더 파일·URL 관리…**에서 iCal URL을 구독하거나 로컬 ICS 파일을 가져옵니다. 앱 안의 Google 로그인이나 OAuth 설정은 필요하지 않습니다.

URL의 기본 갱신 주기는 30분입니다. 수동·15분·30분·1/3/6시간·하루 중 선택할 수 있고 각 행 오른쪽의 갱신 아이콘으로 바로 갱신합니다. 체크박스는 달력 표시 여부이며 삭제 아이콘은 해당 캘린더만 지웁니다. 실패 시 이전 자료를 유지합니다.

날짜를 눌러 일정 제목 하나 또는 여러 개를 선택해 D-Day로 등록합니다. 제목과 날짜만 표시하며 설명·장소·참석자·첨부파일·알림은 저장하지 않습니다. 등록한 D-Day는 독립된 사본이므로 원본 날짜가 바뀌면 직접 수정해야 합니다.

비공개 iCal 주소는 캘린더 접근 열쇠이므로 공유하지 마세요. 주소와 캘린더 사본은 해당 Windows 사용자 범위로 암호화하며 INI·설정 내보내기·진단 로그에 주소를 기록하지 않습니다. 자세한 절차는 [ICS_CALENDAR_SETUP.md](ICS_CALENDAR_SETUP.md), 보존·삭제 안내는 [PRIVACY.md](PRIVACY.md)를 보세요.

한국 공휴일·24절기는 캘린더 연동 탭에서 선택적으로 사용할 수 있습니다. 공공데이터포털의 한국천문연구원 특일 정보 API 인증키가 필요하며 두 자료가 같은 키를 사용합니다. 날짜 팝업에는 해당 명칭을 표시합니다.

## 설정 보관과 업데이트

설정과 일정은 `%LOCALAPPDATA%\MyDDayWidget\dday_config.ini`에 저장합니다. 일정·표시 설정이 바뀔 때 서로 다른 최근 정상 설정 3세대를 보관하며, 위치·크기만 바뀌면 이 백업을 교체하지 않습니다. `dday_config.daily-날짜.ini`에는 날짜별 최초 정상 사본을 최대 14개 보관합니다. **기본 설정 초기화는 D-Day 목록을 유지합니다.** INI와 내보낸 설정 파일은 암호화하지 않습니다.

**설정 관리 → 백업 선택·복원…**에서 날짜·D-Day 개수를 확인해 선택한 뒤 저장하세요. 읽기 실패로 저장 보호가 걸린 경우에는 선택한 내용을 저장하기 전에 복구 확인을 표시합니다. 확인 후에도 기존 원본과 백업은 `Recovery` 폴더에 별도로 보존하며 이 사본은 자동 삭제하지 않습니다. 접근 오류가 계속되면 저장하지 않고 원본을 유지합니다.

3.5.7에서 저장하는 INI 형식은 19이며 기존 정상 INI를 읽어 이어서 사용합니다. 새 파일에는 D-Day 개수와 무결성 확인값을 넣어 잘림·누락·변경을 감지합니다. 설정 파일을 직접 편집하면 검증에 실패할 수 있으므로 환경 설정과 불러오기·내보내기 기능을 사용하세요.

업데이트할 때 앱을 종료하고 새 배포 ZIP의 파일을 교체하세요. 기존 일정과 설정은 유지됩니다. 중요 일정은 설정 내보내기로 먼저 보관할 수 있습니다. 캘린더 주소와 암호화된 사본은 INI 내보내기에 포함하지 않습니다.

## 소스 빌드

Visual Studio/Build Tools의 **.NET 데스크톱 개발**, .NET SDK와 **.NET Framework 4.8 타깃 팩**을 설치합니다. `DDay3.sln`을 열고 NuGet을 복원한 뒤 **Release | x64**로 빌드하세요.

```cmd
msbuild DDay3.sln /restore /t:Rebuild /p:Configuration=Release /p:Platform=x64
```

`build-release.bat`는 Release 빌드와 배포 검사를 실행하고 `artifacts\v3.5.7`에 실행 ZIP·EXE·SHA-256 파일을 만듭니다. Release 빌드가 끝난 상태에서 패키징만 다시 하려면 다음 명령을 사용합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\package-release.ps1
```

GitHub Release 태그는 **`3.5.7`**입니다. 배포 자산 이름은 `DDay3-v3.5.7-win-x64.zip`과 `DDay3_SHA256.txt`를 사용합니다. 태그에는 `v`를 붙이지 않습니다.

실행 시 필요한 고정 버전 라이브러리는 Ical.Net 4.3.1, NodaTime 3.2.0, System.Runtime.CompilerServices.Unsafe 6.0.0입니다. 첫 빌드에서 NuGet으로 복원합니다. PowerShell 스크립트의 UTF-8 BOM과 배치 파일의 CRLF 인코딩을 유지하세요. 정식 Release에는 진단 로그 저장 모듈을 포함하지 않습니다.
