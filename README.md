# D-Day 3 · v3.1.6

시계·음력·달력과 여러 D-Day를 유리 패널에 표시하는 Windows용 무료 위젯입니다. My D-Day Widget v2의 설정을 이어서 사용할 수 있습니다.

- 실행 환경: Windows x64, .NET Framework 4.8 이상. 배포 점검 대상: Windows 10/11 x64.
- 실행 파일: `DDay3.exe`. Python·Qt·별도 앱 NuGet 의존성 없이 Windows의 .NET Framework를 사용합니다.
- 공식 안내: https://mathtime.kr/?page=dday
- 공식 소스·배포: https://github.com/lottoria-dev/MyDDayWidget-Source
- 문의: mathtime.ai@gmail.com

## 주요 기능

- 12/24시간 시계, 작은 오전/오후 표시, 초 표시 선택, 스톱워치.
- 시간·날짜·D-Day 제목·남은 일수·목표 날짜·달력의 글꼴, 굵기, 색상, 크기를 각각 지정.
- **항목별 정수 pt 글자 크기 조절**과 실제 위젯 미리보기. 내부 표시 크기는 창 배율을 소수로 계산해 부드럽게 확대·축소합니다.
- 전체 배경·시계·D-Day 캡슐의 유리판 농도를 각각 5~100% 조절. 글자 선명도는 별도로 유지.
- 밝은 글자·어두운 글자·사용자 지정 색상 모드, 6개 빠른 테마, 대표 색상으로 자동 조화 생성. 유리 색조에는 무채색도 제공.
- 배경 카드가 없는 달력, 연·월 직접 이동, 일요일/월요일 시작, 주말 색상, 음력·윤달·일정 제목 툴팁.
- 한 번에 1~10개 표시하는 휠·키보드 순환 목록. 별도 위치 문구 없이 실제 일정 수만큼 높이 사용.
- 프레임 없는 이동·크기 조절, 격자 맞춤, 항상 위에 표시, 트레이 제어.
- 보조 모니터 위치 유지, 트레이의 `주 모니터로 가져오기`로 수동 복구.
- 자동 실행 등록과 실행 파일 이동 후 경로 복구, INI 저장과 3세대 백업.
- 일정 목록을 보존하는 기본 설정 초기화, 불러오기·내보내기·최근 백업 복원.
- 날짜 오름/내림차순·오늘과 가까운 날순·제목순 정렬, 각 날짜 선택기 오른쪽 ↑↓ 이동. 정렬은 저장 시 확정됩니다.
- 기본 600 DIP(100% 배율에서 약 600px) 설정창, 여섯 행을 함께 보는 글꼴 표, 설정 관리 메뉴.
- 빠른 테마 버튼별 대표 색상 3개와 선택 체크, 영문 표시에서 Solar / Lunar 및 leap month 표기.
- 한국천문연구원 공식 공휴일·24절기 API 선택 연동(사용자 인증키 필요). 자료별 연도 캐시와 오프라인 표시.
- 무채색·낮은 색조 강도·얇은 반사 테두리의 클리어 기본 디자인. 기존 사용자는 설정에서 한 번에 적용 가능.
- 전체 배경·시계·D-Day마다 음각/평면/양각 깊이 조절과 5개 조합 프리셋. 공통 광원 방향·색조와 연동.
- iPhone 위젯을 참고한 연속 곡선 모서리와 얇은 반투명 경계. D-Day 캡슐 좌우 내부 여백을 넓혀 제목과 숫자를 안쪽으로 배치.
- 전체 배경의 얇은 흰색 경계선을 설정에서 켜거나 끄기. 배경 농도·광원과 별도로 바탕화면과의 경계 표시.

## 글자와 달력 조절

설정 → **글꼴·색상 → 항목별 글꼴과 크기**에서 여섯 항목을 한 표로 비교합니다. 각 행의 크기를 입력하거나 `− / +`, 입력칸의 ↑↓ 키로 1pt씩 조절합니다. 다른 항목 값은 그대로 유지됩니다. 범위는 5~150pt의 정수이며 창 크기 조절에 쓰는 전체 확대율과 별개입니다.

예: D-Day 제목 16pt, 남은 일수 22pt, 달력 18pt. 시간과 목표 날짜의 기준값은 바뀌지 않습니다. 크기를 키워 공간이 부족하면 창이 넓어지고 높이가 다시 계산됩니다. 최소 가독성 제한에 걸린 경우 전체 확대율도 올라갈 수 있습니다. 취소하면 글꼴·색상·창 크기를 복원합니다.

새 기본값은 시간 Consolas, 남은 일수/달력 Tahoma, 한글 제목/날짜 맑은 고딕이며 달력은 15pt입니다. 시간 글꼴 목록은 설치된 Consolas, Cascadia Mono, Courier New를 먼저 보여줍니다. 기존 설정의 글꼴·크기는 자동으로 덮어쓰지 않습니다. **서체 적용**은 추천 세트의 글꼴·굵기만 적용하며 항목별 크기와 색상을 유지합니다. 설치되지 않은 서체는 기본 서체로 대체하고 안내합니다.

| 구분 | 추천 세트 | 숫자 / 제목·날짜 |
| --- | --- | --- |
| 시계 우선 추천 | 고정폭 시계 | 시계 Consolas / 나머지 항목은 기본 서체 |
| 영문 추천 | 또렷한 숫자 | Tahoma / Segoe UI |
| 영문 추천 | 부드러운 균형 | Segoe UI / Segoe UI, 제목 중간 굵기 |
| 영문 추천 | 고정폭 숫자 | Consolas / Segoe UI |
| 한글 추천 | 현대적 기본 | Tahoma / 맑은 고딕 |
| 한글 추천 | 간결한 구성 | Tahoma / 돋움 |
| 한글 추천 | 차분한 명조 | Georgia / 바탕 |

빠른 테마와 **대표 색상 선택 → 조화 색상 만들기**는 여섯 항목의 글자색만 바꿉니다. 지정한 유리판 색상·농도와 글꼴·크기는 유지합니다. 유리판 색상은 표시·동작 탭에서 따로 바꿉니다. 테마 선택은 버튼의 체크로 확인하고 개별 색상은 표의 색상칸에서 수정합니다. 별도의 현재 색상 제목·설명은 표시하지 않습니다.

`밝은 글자`는 어두운 배경, `어두운 글자`는 밝은 배경에 사용합니다. 원래 지정 색상을 쓰려면 `사용자 지정 색상 그대로`를 선택합니다. 배경만 투명하게 하려면 **표시·동작 → 유리판 농도**에서 글자 선명도는 100%로 두고 전체 배경·시계·D-Day 다이얼을 따로 낮춥니다. 각 다이얼은 5~100%, 휠·방향키는 1%씩, − / + 버튼은 5%씩 조절합니다. 공통 색조 강도와 색상은 세 유리판에 함께 적용합니다. 유리판은 겹쳐 그려지므로 전체 배경 농도는 그 위 카드의 시각적 인상에도 영향을 줍니다.

표시·동작 탭의 **공통 광원 방향·색조**에서 다이얼의 점을 끌어 빛이 들어오는 위치를 정합니다. 위 0° / 오른쪽 90° / 아래 180° / 왼쪽 270°이며 360°에서 0°로 이어집니다. 드래그는 1°, 휠·방향키는 5°씩 조절합니다. 아래 색조 버튼 또는 직접 선택 색상이 세 패널의 빛에 함께 적용됩니다.

양각은 빛을 받는 가장자리와 바깥 접촉 그림자, 음각은 반대쪽 반사광과 빛을 향한 안쪽 벽의 그림자로 표현합니다. 0에서는 입체 명암을 없애 평면 유리로 표시합니다. 실제 바탕화면 굴절·흐림을 계산하는 기능은 아닙니다. 글자에 그림자·블러·광원 필터를 씌우지 않으며 달력 배경은 투명하게 유지합니다. 방향 변경은 미리보기로 확인하고 저장하면 재실행 후 유지됩니다. 취소하면 이전 방향·색상·농도로 돌아갑니다.

달력 주말 색상은 표시·동작 탭에서 켜거나 끌 수 있습니다. 끄면 지정한 달력 글자색을 주말에도 사용합니다. 공휴일 연동으로 받은 공휴일은 별도로 붉은색으로 표시합니다. 전·후 달 날짜는 현재 달보다 옅게 표시합니다.

## 클리어 디자인과 깊이 조절

새 설치의 기본값은 무채색 `#DCDCDC`, 색조 강도 18%, 전체/시계/D-Day 농도 70/60/60%, 깊이 +35/+20/+20, 광원 315°입니다. 글자는 선명도 100%와 모노 색상 조합을 사용합니다. 기존 INI의 색상·농도를 강제로 덮어쓰지 않습니다.

기존 사용자는 **표시·동작 → 유리판 농도·깊이 → 클리어 기본 적용**을 누르고 저장하면 새 디자인을 쓸 수 있습니다. 이 버튼은 유리 색조·농도·깊이·광원과 글자색·선명도를 바꾸며 일정, 글꼴, 굵기, 글자 크기, 날짜 형식과 표시 옵션은 유지합니다. 취소하면 원래 디자인을 복원합니다.

**전체 배경에 얇은 흰색 경계선 표시**를 켜면 바깥 유리판에 아주 얇은 반투명 흰색 선이 나타납니다. 기본값은 켜짐이며, 배경 농도를 5%로 낮추거나 광원의 색상·방향을 바꿔도 경계선은 유지됩니다. 시계·D-Day 캡슐에는 추가하지 않습니다. 끄면 흰색 경계선만 사라지고 기존 양각·음각의 반사광과 그림자는 유지됩니다. 변경은 즉시 미리보기에 반영되며 저장하면 재실행 후에도 유지되고, 취소하면 이전 선택으로 돌아갑니다.

기존 설정 파일에 경계선 항목이 없으면 켜짐으로 시작합니다. 클리어 기본 적용과 기본 설정 초기화도 경계선을 켜며, 빠른 색상 테마와 깊이 프리셋은 사용자가 선택한 켜짐/꺼짐 상태를 유지합니다.

각 농도 다이얼 아래의 깊이는 전체 배경 −100~+200, 시계와 D-Day −100~+100 범위입니다. 전체 배경의 +100 초과 구간은 접촉 그림자와 부드러운 안쪽 반사광을 확장해 강화유리를 얹은 느낌을 더합니다. v3.1.6에서는 경계를 얇게 정리하고 모서리를 연속 곡선으로 바꾸었으며, 기존 깊이 범위·광원 방향·색조·농도·프리셋 설정은 유지합니다. 숫자는 실제 픽셀 높이가 아닌 시각적 깊이의 강도이며 글자 크기·배치에 영향을 주지 않습니다. 각 슬라이더의 방향키는 1, Page Up/Down은 10씩 조절합니다.

D-Day 캡슐의 좌우 내부 여백은 기준 크기에서 각각 24 DIP입니다. 창 크기에 따라 같은 비율로 확대·축소하며 양쪽에 동일한 반올림 규칙을 적용합니다. 긴 날짜·큰 글자에 필요한 최소 폭에도 이 여백을 반영합니다.

농도·깊이·글자 선명도·색조 강도·광원 각도와 격자 간격·표시 개수는 숫자를 직접 입력할 수 있습니다. Enter 또는 다른 컨트롤로 이동하면 적용하며, 입력칸의 ↑↓는 1씩 조절합니다. 일반 값은 허용 범위로 제한하고 각도는 순환합니다(360 → 0, −45 → 315). 빈칸·문자·소수는 마지막 유효값으로 돌아가며 Esc는 현재 입력을 취소합니다.

| 깊이 프리셋 | 전체 배경 | 시계 | D-Day |
| --- | ---: | ---: | ---: |
| 은은하게 · 기본 | +35 | +20 | +20 |
| 전체 양각 | +70 | +60 | +60 |
| 배경 양각·카드 음각 | +55 | −45 | −45 |
| 전체 음각 | −45 | −55 | −55 |
| 평면 | 0 | 0 | 0 |

깊이 프리셋은 **세 깊이 값만** 바꾸므로 사용자가 고른 색조·농도·광원·글자 설정을 유지합니다. 실제 값이 프리셋과 일치할 때만 체크를 표시합니다. 시계만 음각으로 바꾸는 등 개별 조합도 가능합니다. 광원 다이얼과 깊이 조절은 패널 그리기만 갱신하며, 글자 재조판이나 공휴일 조회를 반복하지 않습니다.

| 불러오기·내보내기·백업·초기화 | 설정창 하단의 설정 관리 메뉴 |

정렬은 한 번 수행하는 작업이며 날짜가 바뀌었다고 자동으로 순서가 변하지 않습니다. `가까운 날순`은 오늘과의 날짜 차이 절댓값을 사용하므로 과거 일정도 포함됩니다. 같은 기준값인 일정은 기존 상대 순서를 유지합니다. 취소하면 정렬 전 순서가 유지됩니다.

날짜 형식은 연-월-일 / 월/일/연 / 일/월/연 중 선택하며 위젯의 날짜·목표 날짜·음력과 달력 팝업의 Solar/Lunar에 공통 적용합니다. 음력 윤달은 한글 `(윤달)`, 영문 `(leap month)`로 별도 표시합니다.

D-Day 날짜 저장과 계산은 양력 기준입니다. 음력은 .NET KoreanLunisolarCalendar의 지원 범위 안에서 제공하는 보조 표기입니다. 스톱워치는 시작·일시정지·초기화를 지원하며 재실행 시 0부터 시작합니다.

시계는 0~9의 글자 폭과 돌출 부분을 측정해 같은 폭의 숫자 자리를 사용합니다. 숫자와 구분자의 위치가 초마다 움직이지 않도록 자리 전체를 가운데 정렬하며, 폭이 부족하면 최종 글자 크기로 다시 조판합니다. 작은 오전/오후 표시는 별도로 배치하고 24시간제에는 그 자리나 공백을 남기지 않습니다. D-Day 캡슐은 확대·축소 때 좌우에 동일하게 반올림한 내부 여백을 적용합니다.

시계는 콜백마다 시스템 시간을 읽고 다음 초 경계로 갱신 시점을 맞춥니다. UI 처리가 밀리면 표시가 늦어질 수 있으며, 하드 실시간 동기화 기능은 아닙니다. 날짜·D-Day 계산은 날짜 변경 시 갱신합니다.

## v2 / 개발 버전에서 업데이트

1. 기존 앱의 `설정 내보내기`로 INI를 별도로 보관하고 앱을 완전히 종료합니다.
2. 새 배포 ZIP을 풀고 `DDay3.exe`를 실행합니다. 기존 자동 실행 경로는 옵션이 켜져 있으면 새 실행 파일로 갱신합니다.
3. 같은 사용자 설정 폴더의 INI를 읽으므로 일정은 유지됩니다. v2·개발 버전·v3를 동시에 실행하지 마세요.
4. 달력이 작으면 글꼴 표의 달력 크기를 키웁니다. 추천 서체를 적용해도 크기는 바뀌지 않습니다.

설정 위치는 `%LOCALAPPDATA%\MyDDayWidget\dday_config.ini`이며 `dday_config.bak1.ini`~`bak3.ini`를 순환 백업합니다. 기본 설정 초기화는 일정 목록과 순서를 유지합니다. 저장할 때 실제 글자 크기에 맞춰 창 높이는 다시 계산될 수 있습니다.

설정 스키마는 13입니다. `panel_depth`, `clock_panel_depth`, `dday_panel_depth`에 −100~100 정수 깊이를 각각 저장합니다. 없는 키에는 +35/+20/+20을 적용하며, 기존 색조·농도는 유지합니다. 새 `glass_light_direction`은 광원 방향(0~359°), `show_solar_terms`는 24절기 표시 여부입니다. 기존 파일에는 기본 광원 315°(왼쪽 위), 24절기 꺼짐을 적용합니다. 세 유리판은 `panel_opacity`, `clock_panel_opacity`, `dday_panel_opacity`에 각각 저장합니다. 기존 INI에 개별 키가 없으면 이전 패널 농도를 세 유리판에 동일하게 적용해 기존 모양을 보존합니다. `size_*`는 정수 pt로 저장합니다. 이전 개발본의 소수 크기는 불러올 때 가장 가까운 정수로 반올림합니다. `calendar_weekend_colors`가 없으면 주말 색상 구분을 켜고, `show_korean_holidays`가 없으면 공휴일 연동은 끕니다. v2로 돌아갈 때는 **v2에서 내보낸 INI**를 불러오세요. v3의 신규 옵션을 v2가 그대로 해석한다는 보장은 없습니다.

## 한국 공휴일·24절기 연동

1. [공공데이터포털의 한국천문연구원 특일 정보](https://www.data.go.kr/data/15012690/openapi.do) 활용신청 후 인증키를 발급받습니다.
2. 설정 → **공공데이터**에서 `달력에 한국 공휴일 표시`와 `24절기 표시` 중 원하는 항목을 선택하고 인증키를 입력합니다. 같은 인증키를 사용하며 옵션은 각각 켜거나 끌 수 있습니다.
3. `연동 확인·새로고침`으로 달력의 현재 연도를 확인하고 저장합니다. 실제 달력 표시도 표시·동작 탭에서 켜야 합니다.

기본값은 꺼짐이며 앱에 공용 키를 넣지 않습니다. 원문/URL 인코딩 인증키를 모두 받습니다. 키는 저장 시 Windows DPAPI의 현재 사용자 범위로 암호화해 `holiday-key.bin`에 보관하며 INI·내보내기·로그에는 기록하지 않습니다. 다른 계정이나 PC에는 키를 다시 입력하세요. `키 삭제`도 저장할 때 확정됩니다. 표시 초기화는 연동을 끄되 기존 키와 캐시는 지우지 않습니다.

연동을 켜면 달력에 보이는 연도를 HTTPS로 비동기 조회합니다. 연도·24절기의 조회 월·인증키만 전송하며 개인 일정·제목은 전송하지 않습니다. 성공한 전체 연도 자료는 설정 폴더의 `HolidayCache/KR-연도.xml`(공휴일), `HolidayCache/KR-Terms-연도.xml`(절기)에 따로 저장해 7일간 재사용합니다. 앱 시작·달력 이동·날짜 변경 시 필요하면 갱신하며 매초 통신하지 않습니다. 네트워크/인증 오류에서는 이전 자료를 유지하고 30분간 자동 재시도를 제한합니다. 수동 새로고침은 즉시 재시도합니다. 연동 확인 버튼은 체크한 자료만 옵션 저장 전에도 요청·캐시 갱신을 수행합니다. 24절기는 API 명세의 필수 월 조건에 따라 12개월을 조회하고, 24개 절기가 모두 확인된 경우에만 연간 자료를 교체합니다. 요청당 12초, 연간 갱신당 45초로 제한하며, 한쪽 실패가 다른 자료를 지우지 않습니다.

공휴일은 붉게 표시하고 날짜 팝업에 명칭만 추가합니다. `공휴일:` 또는 `Public holiday:` 접두 문구는 없습니다. 24절기가 있는 날은 날짜 아래 점을 표시하고 팝업에 입춘·춘분·추분 등 해당 절기 명칭을 표시합니다. 절기 자체는 공휴일로 분류하거나 빨갛게 칠하지 않습니다. 같은 날의 음력·D-Day 제목·공휴일·절기는 함께 볼 수 있습니다. 이름은 제공기관의 한국어 원문을 보존합니다. 임시·대체공휴일도 해당 연도 API 자료에 포함된 경우 표시합니다. 자체 계산으로 추정하거나 누락을 임의로 채우지 않습니다. 자료가 없는 연도와 오류는 설정 상태 및 달력 연·월 툴팁에 표시합니다. D-Day 목록에는 공휴일을 자동 추가하지 않습니다. 실제 키를 사용한 연결 검증은 별도로 필요합니다.

## 빌드와 배포

Visual Studio 또는 Build Tools의 **.NET 데스크톱 개발**, .NET SDK, **.NET Framework 4.8 타깃 팩**을 설치합니다. `DDay3.sln`의 `Release | x64`로 빌드하거나 다음 파일을 실행합니다.

```cmd
build-release.bat
```

성공하면 실행 파일 검증 후 `artifacts/v3.1.6`에 `DDay3.exe`, `DDay3-v3.1.6-win-x64.zip`, `DDay3_SHA256.txt`를 만듭니다. GitHub 태그는 **3.1.6**, 본문은 `RELEASE_NOTES.md`입니다. 생성된 세 파일은 Release 자산으로 게시합니다. 소스 동기화만으로 실행 파일이나 Release가 자동으로 게시되지는 않습니다.

이 저장소용 패키지에는 앱 소스·리소스·빌드 도구·사용 안내·라이선스만 포함합니다. 검사 자료·개발 이력·웹페이지·실행 로그·사용자 INI·인증키·빌드 결과물은 제외합니다. Windows에서 빌드한 뒤 위젯과 설정창을 확인하고 배포하세요.

별도 Developer 구성·배지·탭·메뉴는 제거했습니다. 유지보수용 `Debug | x64`만 `TRACE_DIAGNOSTICS`를 사용하며 진단 모듈은 Release 컴파일에서 제외합니다. 정식판은 로그 파일이나 로그 폴더를 만들지 않습니다. Debug 로그는 `%LOCALAPPDATA%\MyDDayWidget\Logs\DDay3-developer.log`에 4 MiB 단위, 백업 3개로 순환하며 일정 제목·날짜를 기록하지 않습니다.
